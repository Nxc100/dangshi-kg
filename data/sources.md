## 二、DR-06 复核结论汇总

| 编号 | 主入口可达 | 编码 | 与 FRS 登记的差异 |
|---|---|---|---|
| DR-01 | ✅ | GBK | 无（编码符合预期） |
| DR-02 | ✅ | UTF-8 | 主入口改为共产党员网；编码非 GBK；简介缺地点 |
| DR-03 | ✅ | UTF-8 | **原主入口 403 失效**，改用党史资料库人物栏 |
| DR-04 | ✅ | UTF-8 | 无 |
| DR-05 | ✅ | GBK | 无 |
| DR-12 | ✅ | UTF-8 | FRS 未登记，2026-09-16 新增；栏目首页静态列出 366 个日期页 |

**编码判定规则（重要）：** 人民网系并非一律 GBK。文章页 `/n1/…` 声明 `gb2312`，
而部分目录页 `/GB/…` 声明 `utf-8`。故 `kg/crawler/common.py` 已改为
**以页面 `meta charset` 为准、域名规则仅作兜底**（`detect_encoding()`），
按域名硬套 GBK 会把 DR-02、DR-03 的入口页解成乱码。

**网络环境提示：** 复核时本机代理处于 fake-IP 模式（解析出 `198.18.x.x`），
`cpc.people.com.cn` 与 `www.idcpc.gov.cn` 的 **HTTPS 间歇超时而 HTTP 正常**。
登记表中人民网系一律使用 `http://`。换网络环境后可复跑 `check_sources.py` 复核。

**命名策略（自动池正确性的基础）：** 事件名取权威编年条目的**整句表述**，越界即整条弃用，
不在句中截取片段；组织与地点只接受以机构后缀、政区后缀收尾的完整词；文献只接受书名号内的
完整跨度；**人物不做自动识别**（实测 jieba 把「文明」「宣言」标为 nr，而「周恩来」在其词典中
标为 t，正反两类错误都无法用规则稳定滤除），改由 `db/seed_data/core_persons*.py` 人工登记。

**自动抽取准确率（V3 3.4 第 3 步，论文素材）：** 固定随机种子 20260916 抽 200 条逐条人工判定，
**判对 193 / 判错 7，准确率 96.5%**（实体 96.6%、关系 95.5%）。7 个错例集中在三类：指代不明的事件名（「在会议结束前，毛泽东作结论」）、
讲话中的论述片段被当成事件、以通名结尾的地点被判成机构（「纽约联合国总部」）。
评估单与判定结果留在 `data/clean/extraction_sample.csv`，重跑脚本即可复现同一抽样。
